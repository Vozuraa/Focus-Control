Télécharger et lancer Focus Control
Téléchargez le projet. Sur la page GitHub du projet, cliquez sur le bouton Code, puis sur Download ZIP.
Décompressez le projet. Faites un clic droit sur le fichier ZIP téléchargé, puis choisissez Extraire tout (ou utilisez votre logiciel de décompression). Vous obtenez un dossier contenant notamment Focus Control.bat.
Décompressez tools.zip. Dans le dossier extrait, trouvez l’archive tools.zip et décompressez-la au même endroit. Le dossier obtenu doit s’appeler exactement tools et se trouver à côté de Focus Control.bat, et non à l’intérieur d’un autre dossier.
Vérifiez le contenu du dossier tools. Ouvrez-le et assurez-vous qu’il contient les deux fichiers suivants :
PresentMon-2.3.1-x64.exe
PresentMon-LICENSE.txt
Lancez l’application. Double-cliquez sur Focus Control.bat.
Autorisez le lancement. Windows affiche une demande de contrôle de compte utilisateur. Cliquez sur Oui pour lancer l’application avec les droits nécessaires à la capture des FPS. Si vous cliquez sur Non, le lancement est annulé.

Important : ne lancez jamais l’application directement depuis les fichiers ZIP. Décompressez d’abord le projet et tools.zip avant de double-cliquer sur Focus Control.bat.
